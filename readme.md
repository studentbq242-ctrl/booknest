# BookNest — Кітап дүкені және оқу клубы

## Жоба сипаттамасы
BookNest — HTML5 және CSS3 көмегімен жасалған 4 беттік статикалық веб-сайт. Сайтта басты бет, кітаптар каталогы кестесі, оқу клубының ережелері және кері байланыс формасы бар.

## Технологиялар
- Семантикалық HTML5
- CSS3 (Flexbox, CSS Variables, Sticky Header)
- Google Fonts (Playfair Display & Inter)

## Іске қосу жолы
